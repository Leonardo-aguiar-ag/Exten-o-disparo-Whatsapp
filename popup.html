Início:

🚀 Começar em 3 passos

  1. Abra o WhatsApp Web e faça login
  2. Cole a lista de números na aba DISPARO
  3. Escreva a mensagem na aba SCRIPTS e clique ▶ INICIAR

▶ DISPARO

Cole a lista de contatos, um por linha:

85999999999;João Silva
85888888888;Maria
85977777777

Botões principais:

  • ▶ INICIAR — começa o disparo
  • ⏸ PAUSAR — interrompe sem perder progresso
  • ⏹ PARAR — encerra de vez
  • 🔄 RETOMAR ÚLTIMO — continua de onde parou
  • 📁 IMPORTAR EXCEL/CSV — carrega lista de arquivo (.xlsx, .xls, .csv, .txt)
  • 👁 PREVIEW — mostra 3 exemplos da mensagem final

⏳ CONTATO ATUAL mostra há quanto tempo está no contato atual — se passar de 60s é sinal de travamento.

✍️ SCRIPTS

Cada caixa marcada é uma variação. Use:

  • [NOME] → nome do contato
  • {Oi|Olá|Ei} → sorteia uma das opções

Exemplo:

{Olá|Oi|Tudo bem}, [NOME]!
Sou o Leonardo, consultor Hapvida.

Salve combos como Campanha para reutilizar.

🎯 CAMPANHAS

  • Normal — 1 mensagem por contato
  • A/B — testa variações alternadas
  • Drip — sequência em vários dias

No Drip, cada passo tem um campo "Enviar mesmo se respondeu":

  • Se desmarcado (padrão): só envia para quem NÃO respondeu
  • Se marcado: envia para todos, independente de resposta

Marque Agendamento para iniciar em data/hora específica.

📊 CRM

Dashboard do topo:

  • Total — todos os envios
  • OK — enviados com sucesso
  • Erros — inválidos, timeout
  • Respond. — contatos que responderam
  • Digitando — contatos que começaram a digitar (lead quente!)

Taxa de conversão: barra horizontal com % de envios bem-sucedidos e % de respostas.

Envios nos últimos 7 dias: gráfico de barras com volume diário.

Filtros de data: Hoje · Ontem · 7 dias · 30 dias · Tudo.

Botões:

  • 📥 Exportar tudo pra Excel
  • ✅ Exportar SÓ os que responderam
  • 💾 Backup completo (JSON)
  • 📂 Restaurar backup
  • 🗑 Limpar histórico (com opção de desfazer por 2min)

Clique no 📝 de qualquer linha para adicionar uma nota pessoal.

⚙️ CONFIG

👥 Perfis: salva config + scripts + campanhas + lista num perfil. Útil se você trabalha com várias contas/segmentos.

  • Digite um nome, clique 💾 para criar/atualizar
  • Selecione no dropdown para trocar de perfil
  • 🗑 para excluir

Delay: tempo aleatório entre mensagens (recomendado 15–30s).

Pausa por lote: descansa após X envios por Y minutos.

Horário comercial: só dispara dentro da janela.

Duplicatas: pula números já enviados recentemente.

Warm-up: limite diário crescente (número novo).

🎁 Recursos automáticos

  • Backup semanal: toda semana salva backup automaticamente em Downloads/private_bot_backups/
  • Modo escuro automático: detecta preferência do Windows/Mac
  • Notificação de conclusão: aviso do sistema quando o disparo termina
  • Undo: se apagar CRM por engano, botão DESFAZER aparece por 2 minutos
  • Detecção de digitação: quando o contato está digitando, ele é marcado no CRM como lead quente

💡 Dicas rápidas

  • Mantenha o WhatsApp Web aberto durante o disparo
  • Não feche o navegador
  • Comece com poucos contatos para testar
  • Números novos: ative o Warm-up
  • Use 🔄 RETOMAR se algo travar
  • Faça backup manual antes de disparos grandes
